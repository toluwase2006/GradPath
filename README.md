# GradPath

GradPath is a frontend application designed to help Nigerian graduates discover, search, filter, and save internships, entry-level jobs, and graduate opportunities.

## Problem
Early-career opportunities can be difficult to organise because information is scattered across multiple websites and social media platforms.

## Target Users
Nigerian graduates and young job seekers.

## Technology Stack
- React
- Tailwind CSS
- JavaScript
- React Router
- localStorage

## Planned Features
- Browse opportunities
- Search and filter opportunities
- View opportunity details
- Save and remove favourites
- Responsive mobile and desktop layouts

## How to Run Locally

1. Clone the repository.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown in your terminal.
